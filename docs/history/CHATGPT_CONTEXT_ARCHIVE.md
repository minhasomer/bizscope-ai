# ChatGPT Context Archive

Curated record of significant ChatGPT-assisted development sessions. This file captures what was built and decided — not the full transcript.

For full exports: ChatGPT → Settings → Data Controls → Export data.

---

## How to Use This File

When you complete a significant ChatGPT session, add an entry here. Include:
- Session date (approximate if not recorded)
- Model used (GPT-4o, GPT-4, o1, etc.)
- Topics covered (3-6 bullets)
- Key decisions made or outputs produced
- Any caveats or limitations of the approach

Do NOT paste full chat transcripts. Curated summaries only.
